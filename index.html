RAS NOTE

見つける脳をつくる。

意識を向けたいことを決める。
日常の中で見つけたものを記録する。

RAS NOTEは、あなたが大切にしたいものへ 意識を向ける習慣をサポートするノートアプリです。

RAS ATTENTION / DISCOVERY
HOW IT WORKS

見つける習慣を、シンプルに。

01 / SET

RASを設定

今、自分が意識を向けたいことを設定。 最大5つまで登録できます。

02 / NOTICE

発見する

日常で気づいたことや、 ふと目に入ったヒントを発見ノートへ。

03 / REVIEW

振り返る

見つけた最適解や発見を記録。 完了したRASは履歴から振り返れます。

RAS NOTE

見えるものが変わると、
選べるものも変わっていく。

何かを「叶える」ための魔法ではなく、
自分が何に意識を向けるかを決めるための、小さな習慣。
